# Sales Data Analysis Project

# Objective
To analyze sales data and identify key trends, top-performing categories, and regional performance.

# Dataset
The dataset contains information about orders, customers, products, and regions.

# Tools Used
- Python
- Pandas
- Matplotlib

# Analysis Performed
- Total sales calculation
- Sales by category
- Sales by region
- Top 5 products
- Monthly sales trend

# Key Insights
- The Technology category generates the highest sales.
- The West region contributes the most revenue.
- A small number of products account for a significant portion of total sales.
- Sales vary across different months.

# Conclusion
The analysis highlights key sales patterns and can support data-driven decision-making regarding products and regions.
